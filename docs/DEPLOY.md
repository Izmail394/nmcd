# Развертывание на сервере

Инструкция для постоянной публичной ссылки, которую можно дать жюри. Сервис работает без базы данных и
без внешних ключей, нужен только сервер с доступом в интернет.

## Что нужно

| Параметр | Значение |
|---|---|
| Сервер | VPS с Ubuntu 22.04 или 24.04 |
| Ресурсы | 1 vCPU, от 1 ГБ памяти (лучше 2 ГБ), 10 ГБ диска. На серверах с памятью меньше 1,9 ГБ скрипт сам создает файл подкачки на 2 ГБ |
| Расположение | Россия. ЕИС и российские магазины отвечают с российских адресов без блокировок |
| Доступ | Публичный IPv4, открытый порт 80, вход по SSH |

Подойдет любой хостинг с VPS (Timeweb Cloud, Selectel, Beget, REG.RU и другие), самый маленький тариф.

## Быстрая установка

Подключитесь к серверу и выполните одну команду от имени root:

```bash
ssh root@АДРЕС_СЕРВЕРА
```

```bash
curl -fsSL https://raw.githubusercontent.com/Izmail394/nmcd/main/deploy/install.sh | bash
```

Скрипт ставит Docker и Git, загружает код в `/opt/nmcd`, собирает образ и запускает сервис на порту 80.
В конце он печатает адрес вида `http://АДРЕС_СЕРВЕРА`. Это и есть ссылка на развернутое решение.

Проверка с любого компьютера:

```bash
curl http://АДРЕС_СЕРВЕРА/api/health
```

Ответ `{"status":"ok", ...}` означает, что сервис работает. Затем откройте адрес в браузере и выполните
пример расчета.

## Если Docker Hub недоступен

Из России образы с Docker Hub иногда не скачиваются. Тогда укажите зеркало образа Node.js:

```bash
NODE_IMAGE=mirror.gcr.io/library/node:24-alpine bash install.sh
```

Значение запоминается в файле `/opt/nmcd/.env`, при обновлении оно сохраняется.

## HTTPS на своем домене

1. Направьте домен записью A на адрес сервера.
2. На сервере:

```bash
cd /opt/nmcd
```

```bash
DOMAIN=nmcd.example.ru docker compose -f compose.yaml -f compose.https.yaml up -d --build
```

Прокси Caddy сам получит сертификат. Сервис будет доступен по `https://nmcd.example.ru`.

## Обновление, остановка, журнал

```bash
cd /opt/nmcd && git pull && docker compose up -d --build
```

```bash
docker compose stop
```

```bash
docker compose logs --tail 80
```

Отчеты хранятся в томе `nmcd-data`. Полная очистка вместе с отчетами: `docker compose down -v`.

## Запуск без Docker

Нужен Node.js 20 или новее:

```bash
cd /opt/nmcd && npm ci --omit=dev && HOST=0.0.0.0 PORT=80 node src/server.js
```

Для постоянной работы оформите команду как службу systemd.

## Безопасность

- В сервисе нет входа: любой, кто знает адрес, может запускать расчеты и видеть историю расчетов.
  Публикуйте адрес только жюри и закройте порт после проверки (`ufw deny 80` или остановка сервиса).
- Одновременно выполняется не больше трех расчетов, остальные получают просьбу повторить запрос позже.
- Наружу уходят только поисковые фразы и коды ОКПД2 в запросах к открытым источникам.

## Статус проверки

Сервис и тесты проверены локально на Node.js. Сборку образа и скрипт установки на чистом сервере
запустите и проверьте сами при первом развертывании: в среде разработки Docker не был установлен.
