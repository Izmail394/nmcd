# Типовые сценарии

Результаты получены 14.11.2026 живыми запросами к источникам. Цены в магазинах меняются, поэтому при
повторении числа будут другими; структура результата и правила — те же. Чтобы повторить расчёт
точно, запустите сервис с `SNAPSHOT_MODE=record`, а затем с `SNAPSHOT_MODE=replay`.

В этих прогонах отвечали ЕИС, ЭТМ, Яндекс.Маркет, Регард и Портал поставщиков; Комус, ГИСП и ЕАТ
«Берёзка» блокировали автоматические запросы и показаны в отчётах как недоступные.

## 1. Фасованный товар с числовыми характеристиками

**Вход**

```json
{
  "description": "Бумага офисная А4, плотность 80 г/м2, пачка 500 листов, белизна не менее 146%",
  "quantity": 200,
  "unit": "упак",
  "okpd2": "17.12.14.110"
}
```

**Что делает сервис**

- Выделяет предмет «Бумага офисная А4», существенные характеристики: плотность 80 г/м2, белизна не
  менее 146 %, формат A4; фасовку «1 упак = 500 листов» учитывает пересчётом цены.
- Находит 53 предложения в пяти источниках, из них 15 — позиции исполненных контрактов ЕИС.
- Характеристики контрактов сопоставляет по КТРУ: «Масса бумаги площадью 1м2: ≥ 80 и < 90 Грамм»
  подтверждает плотность 80 г/м2; совпадение кода ОКПД2 засчитывается как подтверждённая характеристика.
- Исключает: другую плотность и формат A3 — несопоставимые характеристики (9); предложения, где
  существенные характеристики не подтверждены, в том числе цветную бумагу — недостаток данных (30);
  пачки по 100 листов — несопоставимая фасовка; одну цену вне диапазона — аномальная.
- Сопоставимых цен контрактов достаточно, поэтому 8 сопоставимых розничных цен (670–780 руб.) в расчёт
  не берутся и помечаются «ниже по приоритету источников».

**Результат**

| Показатель | Значение |
|---|---|
| Цен в расчёте | 4, все — контракты ЕИС, заключённые с июля по октябрь 2026 года (по одной цене на контракт) |
| Цены за 1 упак, руб. | 332,70; 350,00; 328,58; 335,00 |
| Цена за единицу | 336,57 руб. |
| Коэффициент вариации | 2,77% (порог 33%) |
| **НМЦД** | **67 314,00 руб.** = 200 × 336,57 |
| Надёжность | высокая, 94 из 100 |

Без ЕИС тот же расчёт по розничным ценам даёт 738,00 руб. за пачку и НМЦД 147 600,00 руб. — более чем в
2 раза выше цен исполненных контрактов.

Правило «один контракт — одно наблюдение»: если в контракте несколько подходящих позиций, в расчёт идёт
первая, остальные помечаются «другая позиция того же контракта» (их можно вернуть вручную).

## 2. Товар в единицах длины с пересчётом из бухт

**Вход**

```json
{
  "description": "Кабель силовой ВВГнг(А)-LS 3х2,5 мм2, напряжение 0,66 кВ",
  "quantity": 500,
  "unit": "м",
  "okpd2": "27.32.13"
}
```

**Что делает сервис**

- Приводит «0,66 кВ» к 660 В, выделяет типоразмер 3x2.5.
- Цены ЭТМ опубликованы за метр и берутся как есть; цены маркетплейсов за бухту делятся на длину из
  названия («2201 руб. за 10 м → 220,10 руб./м»), поправка записывается в отчёт.
- Исключает сечение 3х1,5 — несопоставимый типоразмер; предложения без напряжения — недостаток
  данных; «кабель медный ВВГ НГ» — низкое сходство наименования.

**Результат**

| Показатель | Значение |
|---|---|
| Цен в расчёте | 9 (ЭТМ — 8, Яндекс.Маркет — 1) |
| Диапазон цен за 1 м | 173,55 – 218,17 руб. |
| Цена за единицу | 195,80 руб. |
| Коэффициент вариации | 6,51% |
| **НМЦД** | **97 900,00 руб.** = 500 × 195,80 |
| Надёжность | высокая, 84 из 100 |

ЕИС по этому запросу вернул три позиции с обобщённым наименованием КТРУ «Кабель силовой с пластмассовой
изоляцией низкого напряжения» (цены за километр приведены к метру: 21,15–109,97 руб.); их характеристики
не совпали с требуемым типоразмером, поэтому расчёт выполнен по ценам каталога и маркетплейса.

## 3. Товар с артикулом и комплектами

**Вход**

```json
{
  "description": "Картридж для лазерного принтера HP CF283A, ресурс не менее 1500 страниц",
  "quantity": 20,
  "unit": "шт"
}
```

**Что делает сервис**

- Артикул CF283A обязателен: картриджи других моделей исключаются как «другая модель или артикул».
- Комплекты приводятся к цене за штуку («(4 штуки)» за 1 719 руб. → 429,75 руб.).
- Оригинальные картриджи за 10 160, 4 177 и 2 498 руб. исключаются как аномальные цены тремя
  последовательными проходами правила межквартильного размаха: остальные предложения — совместимые
  аналоги. Если нужен именно оригинал, это надо указать в описании.
- В ЕИС нашлись два контракта с CF283A (222,34 и 227,07 руб.), но ресурс картриджа в них не указан —
  они исключены как «недостаток данных»; включить их можно вручную.

**Результат**

| Показатель | Значение |
|---|---|
| Цен в расчёте | 5 (Яндекс.Маркет — 4, Регард — 1) |
| Цены за 1 шт, руб. | 530,00; 711,00; 401,00; 814,00; 600,00 |
| Цена за единицу | 611,20 руб. |
| Коэффициент вариации | 26,13% |
| **НМЦД** | **12 224,00 руб.** = 20 × 611,20 |
| Надёжность | средняя, 71 из 100 |

Выдача маркетплейсов меняется от запроса к запросу, поэтому в этом сценарии результат заметно
колеблется между прогонами (в предыдущем прогоне — 482,84 руб. за штуку по 8 ценам).

## 4. Недостаточно данных — цена не формируется

**Вход**

```json
{
  "description": "Услуги по разработке мобильного приложения для iOS",
  "quantity": 1,
  "unit": "усл. ед"
}
```

**Результат**

Источники вернули 35 предложений, все исключены: 33 — другой предмет (товары, а не услуга), 2 — дубли.
Статус `insufficient_data`, НМЦД не рассчитана, сообщение: «Не найдено ни одного сопоставимого
предложения с ценой. Цена не сформирована».

Дальше пользователь добавляет коммерческие предложения вручную (не менее трёх) — расчёт выполняется
по ним по тем же правилам.

Тот же исход, когда цен меньше трёх или выборка неоднородна (коэффициент вариации выше 33%): сервис не
выдаёт необоснованное значение, а называет причину. Три позиции одного контракта — это одна цена, поэтому
«Услуги по обслуживанию сплит-систем» с одним подходящим контрактом тоже заканчиваются без цены.

## 5. Только коммерческие предложения, без поиска

**Вход** (все источники сняты, три предложения введены вручную)

```json
{
  "description": "Стул офисный на колёсах, ткань, чёрный",
  "quantity": 15,
  "unit": "шт",
  "sources": [],
  "manualOffers": [
    { "title": "Стул офисный на колёсах, ткань", "priceRub": 4200, "unit": "шт", "supplier": "ООО «Альфа»" },
    { "title": "Стул офисный на колёсах, тканевый", "priceRub": 4550, "unit": "шт", "supplier": "ООО «Бета»" },
    { "title": "Стул офисный на колёсах, ткань", "priceRub": 4390, "unit": "шт", "supplier": "ИП Иванов" }
  ]
}
```

**Ожидаемый результат**

Цена за единицу — (4 200,00 + 4 550,00 + 4 390,00) / 3 = 4 380,00 руб.; коэффициент вариации 4,00%;
НМЦД = 15 × 4 380,00 = 65 700,00 руб.; предупреждения: минимально допустимое число цен, все цены из
одного источника. Сеть не используется, расчёт полностью детерминирован.

## Ручная правка решения

В любом отчёте у предложения есть «Исключить» или «Включить в расчёт». После нажатия расчёт
повторяется по сохранённым данным без обращения к источникам, предложение помечается «изменено
вручную», в ходе расчёта появляется шаг «Ручные правки», а автоматическое решение можно вернуть.
