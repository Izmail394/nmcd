# Как добавить источник цен

Источник — это один модуль `src/sources/<id>.js` и одна запись в `config/sources.json`.
Основная логика (нормализация, сопоставимость, расчёт, отчёт) при этом не меняется.

## Контракт

HTTP-клиент и типы ошибок — в [`src/core/http.js`](../src/core/http.js); поля предложения (`RawOffer`) описаны в [архитектуре](ARCHITECTURE.md#контракты-данных).

```js
import { SourceError, parseJson } from '../core/http.js';

/** Чистая функция: тело ответа -> предложения. Тестируется на сохранённых фикстурах. */
export function parseSearch(body, fetchedAt) { /* ... возвращает массив предложений */ }

const createSource = (options = {}) => ({
  id: 'example',
  name: 'Пример',
  kind: 'marketplace',
  homepage: 'https://example.ru',
  async search(query, ctx) {
    const response = await ctx.http.get(`https://example.ru/search?q=${encodeURIComponent(query.text)}`, { signal: ctx.signal });
    return parseSearch(response.body, response.fetchedAt).slice(0, query.limit);
  },
});
export default createSource;
```

## Правила

1. **Только `ctx.http`.** Не вызывайте `fetch` напрямую: клиент даёт таймауты, повторы,
   паузу между запросами к хосту и запись/воспроизведение ответов.
2. **`fetchedAt` берётся из `response.fetchedAt`**, а не из `new Date()` — в режиме
   воспроизведения это исходная дата получения данных.
3. **Разбор — в чистых функциях** `parse*(body, fetchedAt)`, без сети. Тесты работают на
   фикстурах из `test/fixtures/<id>/`.
4. **Ошибки:**
   - источник ответил, но ничего не нашёл → `[]`;
   - структура ответа изменилась (нет ожидаемого контейнера/поля) → `throw new SourceError('parse', '…')`;
   - капча или страница антибота с кодом 200 → `throw new SourceError('blocked', '…')`;
   - сетевые ошибки, таймауты, 4xx/5xx клиент превращает в `SourceError` сам.

   Отдельное предложение без цены или ссылки пропускается, остальные возвращаются.
5. **Данные как в источнике.** `priceRub` — цена за опубликованную единицу продажи, `unitText` —
   единица как написана («шт», «упак», «пачка 500 л»). Пересчёт в единицу закупки делает ядро.
   Не выдумывайте значения: неизвестное поле не заполняется, `vat: 'unknown'`.
6. **`url` ведёт на конкретное предложение** (карточку товара, контракт), а не на страницу поиска.
7. **Характеристики** — объект «название → значение» как в источнике. Если в выдаче их нет, можно
   дозапросить карточки первых `detailLimit` предложений (по умолчанию не больше 6).
8. **Без обхода защиты.** Никаких капча-решателей, подмены отпечатков, прокси. Если источник
   блокирует автоматические запросы — адаптер честно возвращает `SourceError('blocked')`.
9. Во внешние сервисы передаются только открытые данные: поисковая фраза и код ОКПД2.

## Проверка

```bash
node scripts/try-source.js <id> "бумага офисная А4"
```

```bash
node --test src/sources/<id>.test.js
```

## Подключение

`config/sources.json`:

```json
{ "id": "example", "enabled": true, "options": { "detailLimit": 6 } }
```
