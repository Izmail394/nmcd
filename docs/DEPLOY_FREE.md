# Бесплатный демо-стенд

Вариант для случая, когда нет сервера и нет денег. Сервис запускается на бесплатном хостинге и
работает **по сохраненным ответам реальных источников** (демо-режим), поэтому ему не нужен доступ к ЕИС
и магазинам. Это важно: ЕИС не пускает зарубежные адреса, а бесплатные хостинги находятся за рубежом.

## Что умеет демо-стенд

- Четыре примера из интерфейса (бумага А4, кабель, картридж, случай «нет данных») считаются с теми же
  цифрами, что и на живой версии, со ссылками, причинами исключения, формулами и выгрузкой DOCX.
- Свою закупку можно посчитать по коммерческим предложениям, добавленным вручную.
- Незнакомый поисковый запрос источники не найдут: в отчете будет пояснение, что это демо-режим.
- В интерфейсе показана плашка «Демо-режим» с датой записи ответов.

Полная версия с поиском в реальном времени запускается из репозитория (`docs/DEPLOY.md`).

## Развертывание на Render (бесплатно)

1. Откройте <https://render.com> и зарегистрируйтесь (проще через GitHub).
2. Нажмите **New, затем Web Service**.
3. Выберите **Public Git Repository** и вставьте адрес `https://github.com/Izmail394/nmcd`.
4. Заполните форму:

| Поле | Значение |
|---|---|
| Name | `nmcd-demo` (или любое) |
| Language / Runtime | **Docker** |
| Branch | `main` |
| Instance Type | **Free** |

5. В разделе **Environment Variables** добавьте две переменные:

| Ключ | Значение |
|---|---|
| `SNAPSHOT_MODE` | `replay` |
| `SNAPSHOT_DIR` | `/app/demo/snapshots` |

6. Нажмите **Create Web Service**. Сборка занимает от 3 до 6 минут.
7. Адрес появится вверху страницы сервиса, вида `https://nmcd-demo-xxxx.onrender.com`. Откройте его и
   нажмите любой пример.

Вместо шагов 2 до 6 можно использовать файл `render.yaml` из репозитория: **New, Blueprint**, выбрать
репозиторий.

## Ограничения бесплатного тарифа Render

- После 15 минут без обращений сервис «засыпает», первое открытие после сна занимает около минуты.
  Перед проверкой жюри откройте адрес сами, чтобы сервис проснулся.
- Отчеты, созданные на стенде, хранятся только до перезапуска сервиса.
- Памяти 512 МБ хватает.

## Обновление записанных ответов

С российского адреса (дома, не на зарубежном сервере):

```bash
node scripts/record-demo.js
```

Затем закоммитьте каталог `demo/snapshots` и отправьте в репозиторий, Render пересоберет сервис сам.
